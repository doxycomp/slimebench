# GLSL 4.3 compute — the portable GPU route

The same tick as CUDA, as three compute shaders driven from C. It is the
target that made class G into a comparison rather than a single number, and it
is also the one whose numbers need the most care in reading.

**The shaders are the interesting part of this directory.** They used to be
embedded as C string literals; they now live in `shaders/` as real files, the C
header is generated from them, and the host reports an FNV-32 of the source it
compiled. That is what lets [`impl/pygl`](../pygl/) prove it runs the same
shaders, and what lets [`impl/vulkan`](../vulkan/) reuse the same bodies
through a mechanical transformation.

Two things the shaders do that are not obvious:

- **The deposit is an integer hit counter**, not a float atomic. `atomicAdd` on
  a float is not deterministic — the arrival order of invocations decides the
  rounding — so `agents.comp` counts and `merge.comp` turns counts into
  deposits once per tick, in a fixed order.
- **The accumulator in `diffuse.comp` is `precise`.** Without it a driver may
  reassociate the nine additions or contract the centre term into an FMA. It is
  necessary and not sufficient: `precise` says nothing about the rounding of
  the division, which is why the real GPU drivers still deviate.

**A warning about the numbers.** Under WSL2 this path is Mesa translating GL to
D3D12: three dispatches, three barriers and a `glFinish` per tick, all through
GL to DXIL to D3D12. Throughput stays flat across four orders of magnitude,
which says the translation layer and not the GPU is the bottleneck — a software
Vulkan device on the CPU beats this path on the discrete GPU. On a native Linux
GL driver the gap to CUDA would almost certainly be much smaller.

## Reading order

`shaders/common.glsl` for the bindings, then `shaders/agents.comp`,
`diffuse.comp` and `merge.comp` — sixty lines between them. `slimebench_gl.c`
is buffer setup and dispatch.

## Building

```bash
make -C impl/glcompute PROFILE=default
```

`gen_shaders.py` regenerates `gl_shaders.h` from `shaders/`; CI re-runs it and
fails if the committed output differs.
