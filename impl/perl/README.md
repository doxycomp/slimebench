# Perl — the other end of the range

Conformance tier B by default, tier A with `--strict-f32`.

Perl has 64-bit integer values, so the 32-bit PRNG arithmetic needs explicit
masking after every operation — Perl will happily give a 64-bit result where C
would have wrapped. That masking, plus forcing every float intermediate through
a pack/unpack round-trip for tier A, is most of what this port is.

It is the slowest target in the project by a wide margin, and it earns its
place twice. First, at tier B it lands within a fraction of a per cent of pure
Python, which says interpreter dispatch dominates so completely that the
language underneath has almost stopped mattering. Second, its class P strategy
is one nothing else uses: **replication across processes**, which is exactly
the serial chain repeated, so it is bit-exact for a reason unrelated to how
every other port gets there.

The preset used for Perl in the sweeps is `tiny`, because `medium` would take
hours.

## Reading order

`slimebench.pl` — one file, and the masking is visible on every line that
touches the PRNG. `slimebench-render.pl` binds SDL2 and raylib through
`FFI::Platypus`, which is where the class R result comes from.

## Building

Nothing to build for the headless target. The render target needs the shim in
[`impl/shim`](../shim/).
