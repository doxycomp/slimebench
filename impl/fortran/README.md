# Fortran — the port that needed no argument

Every other language in this project needed a paragraph explaining how it
reaches bit-exactness: a flag, an explicit conversion, a language-version
guarantee, a C stub. Fortran needed none. It has had native single precision
since 1957 and an arithmetic model that says what it does, so `real(real32)`
is binary32 and each operation rounds. That combination is the finding here,
not the rank.

The rank is worth stating anyway, because it is the one people guess wrong:
Fortran sits behind four garbage-collected or JIT-compiled languages in class S
on this workload. That is not a claim about Fortran — it is a claim about what
a flat float array with a four-way branch per element measures, which is
home ground for everybody.

Class P is three OpenMP directives and nothing else: `parallel do` over the
agent pass, `atomic` on the deposit, `parallel do` over the stencil. No bin
buffers, no prefix sum, no explicit barrier. **And it is tier A at every thread
count**, which is not a property of the atomic but of the workload: SPEC-1's
deposit adds a constant, so a cell's final value is its start plus a count and
no arrival order can change it. Swap the constant for anything agent-dependent
and it stops being exact immediately, while `binned` keeps working — which is
why the spec defines `binned` and not this.
