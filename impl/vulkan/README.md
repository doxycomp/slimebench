# Vulkan compute — one shader, three vendors

CUDA runs on one vendor. The GLSL 4.3 host runs anywhere OpenGL does, which
under WSL2 means Mesa translating to D3D12. Vulkan is the only one of the three
that reaches an AMD, an Intel and an NVIDIA part through the same driver
interface — which is what turns "how fast is this GPU" from a question about
one vendor into a question about a machine.

The host takes a device *kind* rather than an index (`--device
discrete|integrated|cpu|N`), so one build exercises everything present.

**The shader bodies are shared with [`impl/glcompute`](../glcompute/), and must
stay shared** — otherwise class G stops being a comparison of two APIs running
the same computation and becomes a comparison of two programs. Exactly one
thing in them is not valid Vulkan GLSL: the default-block `uniform`
declarations, which Vulkan does not have. `gen_shaders.py` replaces that block
with push constants and a set of `#define`s mapping the old names onto it, then
asserts that every line below the prelude is byte-identical to the OpenGL
version.

## What the checksums showed

The five GPU hosts sort into three groups, and the grouping is the result:

- **CUDA and the software Vulkan device are bit-exact** against the C reference
  at every preset. So nothing in this port, the SPIR-V, or the push-constant
  plumbing is approximating anything.
- **The NVIDIA and AMD drivers are byte-identical to each other** and both
  differ from the reference. Two independently written drivers landing on the
  same wrong answer is not coincidence — it is the same permitted rounding of
  the division, which `precise` cannot forbid.
- **The GL path is a third answer**, and much slower than either.

One flag carried the whole exactness result: `glslc -O` reassociates past
`precise`, on every device including the software one. `-O0` costs nothing
measurable and is the difference between a conformance result and a plausible
one. `build.sh` compiles with `-O0` for that reason and not by oversight.

## Reading order

`gen_shaders.py` first — it is short and it defines what "the same shader"
means here. Then `slimebench_vk.c`: descriptor sets, the ping-pong, the push
constant struct with its `_Static_assert` on the layout.

## Building

```bash
bash impl/vulkan/build.sh default
```

SPIR-V is compiled at build time rather than committed, because a `.spv` blob
is not reviewable and the toolchain that produces it is pinned in
[`versions.env`](../../versions.env). Class G is
[docs/RESULTS.md](../../docs/RESULTS.md) §9.
