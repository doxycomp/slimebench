=== D. straight-line code against branchy code
   The stencil is nine loads and ten arithmetic operations with no
   branch in it. The agent pass makes a data-dependent four-way turn
   decision per agent per tick, which is where profile-guided
   optimisation should have something to work with. The two are timed
   separately by every port, so the question needs no new workload.
